# Destinia iOS — port experimental

Projeto pessoal e privado para executar Destinia no iPhone. Esta versão experimental reaproveita o motor WebAssembly existente no repositório `sugyua/destinia` sem alterar o port para Windows.

**Estado:** fontes de desenvolvimento, não é um IPA compilado/testado. Não publicar assets originais, saves ou credenciais. O workflow macOS gera um IPA não assinado, que precisa de assinatura pessoal para instalação.

Consulte os demais arquivos do projeto após a importação.
