# Aviso de terceiros e escopo

Este projeto fornece um novo invólucro iOS para os fontes e recursos locais do repositório https://github.com/sugyua/destinia.

- A engine, a marca e os recursos originais Destinia pertencem aos respectivos titulares, incluindo GAMEVIL/Everple conforme identificado pelo projeto de origem.
- A biblioteca ARM e os assets são copiados no build somente para uso pessoal; não são incluídos neste ZIP de fontes. O usuário deve ter uma cópia lícita.
- Unicorn.js está sujeito ao licenciamento informado no arquivo `web/dist/vendor/UNICORN-LICENSE.txt` do repositório original (GPL-2.0); outras dependências têm seus próprios termos.
- Nenhuma licença para os ativos proprietários é concedida pelo pacote atual.
- Não publique o IPA nem os assets empacotados sem revisar direitos e obrigações legais.
